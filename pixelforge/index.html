    How it works & tips
    1 · UploadA screenshot is validated and downscaled locally in your browser.
    2 · GenerateA vision model returns structured JSON with HTML, CSS and JS files.
    3 · SanitisePaths, sizes and remote references are checked before anything is shown.
    4 · Preview & editThe page runs in a locked-down sandbox. Edits update the preview.
    5 · ExportDownload a ZIP with all files and a README.
    • Crop screenshots to the area you want rebuilt; smaller images are faster and cheaper.
    • Choose the viewport the screenshot was captured at so the layout is matched first.
    • Photos become neutral placeholders: the output never loads external assets.
    • Use Extra instructions for style preferences, e.g. “use CSS custom properties for the palette”.
